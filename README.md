# FlowTrace

FlowTrace watches a bank's payments and catches money-mule and scam patterns before the money is cashed out. It narrows about 1,000,000 payments a day down to the 10–15 cases that need an analyst, explains each case with evidence, and suggests which accounts to hold.

Built for **Graph Hacks: Context for AI Agents** (WeMakeDevs × FalkorDB, Oct 15–18, 2026).

**Track:** Track 1, Agents That Act on Connected Data
